# CBC Frontend

A modern and responsive frontend application built with **React, Vite, and Tailwind CSS**.

This project focuses on building a clean, responsive user interface with reusable components, modern frontend development practices, and a production-ready project structure.

## 🚀 Live Demo

[View Live Demo](https://cbc-frontend.vercel.app/)

## 📌 Features

* ⚡ Fast development with **Vite**
* ⚛️ Built with **React**
* 🎨 Styled with **Tailwind CSS**
* 📱 Responsive design for different screen sizes
* 🧩 Reusable React components
* 🔄 Dynamic UI interactions
* 🗂️ Organized and maintainable project structure
* 🚀 Deployed with **Vercel**

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/HimashGuruge/cbc-frontend.git
```

### 2. Navigate to the project

```bash
cd cbc-frontend
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will be available at the local development URL shown in your terminal.

## 🏗️ Build for Production

Create an optimized production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## 🔍 Code Quality
